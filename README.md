Tugas CRUD Data Pesanan LaundryWoy
Website CRUD data pesanan laundry menggunakan PHP dan MySQL (XAMPP), tugas individu minggu 2.
Dibuat dengan PHP, MySQL, dan XAMPP.
Yang bisa dilakukan Lihat daftar pesanan (index.php) Tambah pesanan baru (index.php) Edit data pesanan (edit.php) Hapus data pesanan (hapus.php)

Isi file
koneksi.php : Untuk menyambungkan ke database 
index.php : halaman utama, menampilkan data dari tabel dan form tambah 
edit.php : form edit data pesanan 
hapus.php : proses hapus data pesanan 
database.sql : file untuk bikin database dan tabelnya

Cara Menjalankan
Nyalakan Apache dan MySQL di XAMPP. Buka phpMyAdmin (localhost/phpmyadmin), masuk ke tab SQL, lalu jalankan isi file database.sql.
